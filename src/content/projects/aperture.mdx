Aperture is a set of static files that IRIS serves itself. The browser calls IRIS's own SysAdmin REST API directly,
signed in as you, so IRIS checks your privileges on every call and audits your changes under your name. It also runs
interoperability productions, SQL and the FHIR servers of IRIS for Health, through the APIs IRIS's own tools use.

## What it does differently

- **See who loses what before you save.** Remove a role from a user and the review lists every privilege that user
  loses, before anything is sent.
- **Health check.** Sixteen read-only checks run with your own access; every finding says what it means, what to do,
  shows its evidence and opens the screen that fixes it.
- **Similar log entries.** A small read-only log reader, written in Embedded Python, indexes the instance's messages
  log with IRIS Vector Search, so an entry shows the others worded like it.
- **Long jobs in one place.** Integrity checks, compactions and the like land in a Job Center with their console
  output and progress.

## Try it

The [online demo](https://mxsalata.github.io/aperture/) runs a simulated IRIS inside the page, so you can change
whatever you like. On real IRIS it's one Docker command or one IPM package; the
[README](https://github.com/MxSalata/aperture#readme) has both.
