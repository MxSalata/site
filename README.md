# mxsalata.com

The source of [mxsalata.com](https://mxsalata.com): a static site built with [Astro](https://astro.build) and served
by Cloudflare Workers.

```sh
npm ci
npm run build              # writes dist/
sh scripts/check-dist.sh   # checks the build's output
```

Node 22.23.4 or later (see `.nvmrc`).
